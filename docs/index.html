Kane / Kanaloa 是运行在你电脑上的 Agent 工作台。
在持续对话中推进任务，让每一步工作都有着落。

开始使用 查看源码
01

持续对话

保留讨论，接住下一步。流式回复、追加指令与分支对话，让工作在同一个空间里延续。

02

并行任务

不同任务，各有上下文。在独立工作之间切换，把注意力放在此刻最需要你的地方。

03

由你掌控

使用自己的模型服务。通过审批、取消与可选 Loop，决定 Agent 如何继续工作。

两条命令，开始工作。

先安装 Node.js 24 LTS 与 Python 3.11+，下载并解压源码，在项目目录打开终端。

● ● ●npm run setup
● ● ●npm start

打开 http://127.0.0.1:3000，填写自己的 Base URL、Model 与 API Key。
